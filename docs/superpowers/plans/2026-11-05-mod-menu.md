# In-game mod menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** F9 in `gt_play` opens a MODS page that lists installed mods and turns each on/off at once, saved to its `mod.toml`.

**Architecture:** mods with `enabled = false` are loaded but inactive; the hook trampoline gates on a per-mod atomic `active`
read once per call. A host-side menu model (`host/mod_menu`) owns the list and the toggle (flag + manifest rewrite). An
lcs-recomp patch lets the host register an extra overlay page opened with F9; the four overlay renderers draw a title/footer
taken from the view.

**Tech Stack:** C++20, clang, CMake/ctest, lcs-recomp (patched via `tools/patches/lcs-recomp/` + `tools/setup.sh`), SDL2.

**Spec:** `docs/superpowers/specs/2026-11-05-mod-menu-design.md`

## Global Constraints

- Never edit game code or `recomp/`; no game data in git; heavy builds in `gt-heavy.slice` (AGENTS.md § memory cgroup), clang.
- Real-time runs take `tools/cpu_lock.sh` (holds < 30 min).
- `GT_NO_MODS=1`, `--decomp diff` and synthetic cases still load no mods.
- The startup log line `[mods] loaded: <ids> skipped: [...]` keeps its format (checks grep it); inactive mods are listed as
  skipped with reason `disabled` exactly as today, so `mod_pedals_check.sh --disabled` still passes.
- Commits: English, Conventional, trailers `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and
  `Claude-Session: https://claude.ai/code/session_01CPECciFYErXe7y49BY4UVc`.

## Review Focus

1. Toggle during a hooked call: the trampoline must use one `active` value for the whole call (no half-modded call).
2. Inactive trampoline must leave `ctx.pc` = hooked address while calling `Hook.original` (decompiled trampolines find themselves by it).
3. `mod.toml` rewrite keeps comments/other keys, handles a missing `enabled` line and an unwritable file (row shows `SAVE FAILED`).
4. No provider registered → F9 does nothing and the F10 overlay looks exactly as before (lcs-recomp's own tests).
5. A mod that failed to load is listed `ERROR` and cannot be toggled.
