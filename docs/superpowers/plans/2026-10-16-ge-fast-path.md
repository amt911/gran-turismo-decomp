# GE Fast Path Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut the GE thread's per-draw CPU cost for GT's common draw by at least 30 % (`lists` ms/s, two cores pinned, x4 race) with byte-identical output to Vulkan.

**Architecture:** Part 1: the list executor (`host/gt_ge_exec.cpp`) keeps a draw-state revision bumped by any register change except per-draw ones, and passes it to `render_ge_primitive`, whose descriptor and lighting caches already key on it. Part 2: a fast path in the renderer for GT's quad strips that, on a revision hit, reuses the per-revision descriptor, texture readiness and hardware transform, and hands raw vertex bytes to one new backend call that decodes straight into `UploadVertex`. Each part ships as its own PR with a byte-for-byte verify mode.

**Tech Stack:** C++20 (host + lcs-recomp patches under `tools/patches/lcs-recomp/`), CTest plain executables (`host/tests/*_test.cpp`), Vulkan backend, bash tooling (`tools/gpu_gate.sh`, `tools/gpu_perf.sh`, `tools.decomp_gate`).

**Spec:** `docs/superpowers/specs/2026-10-16-ge-fast-path-design.md`

## Global Constraints

- Output identical: the same vertices, indices, batches and uniforms reach Vulkan as before (verify modes report 0 mismatches).
- Goal: `lists` −30 % or better, `taskset -c 0,1 tools/gpu_perf.sh build OUT 4 220`, same-session A/B.
- Excluded from the revision: 0x01, 0x02 (vertex/index address), 0x04 (PRIM), 0x10, 0x13 (BASE/OFFSET), 0x08-0x0F (list flow), 0xC8 (texture level; its three derived descriptor fields are recomputed per draw). Everything else bumps it, including matrices and lights.
- Verify modes: `GT_GE_REVISION_VERIFY=1` (part 1), `GT_GE_FASTPATH_VERIFY=1` (part 2); mismatches counted in the perf log.
- Fast path only for: hardware transform, primitive 4, not indexed, no lighting, no UV generation, morph 1, no weights, no normals, no flat shading, texture ready or untextured, contiguous vertex bytes in guest memory. Everything else unchanged.
- lcs-recomp changes go in new patches `0046-*.patch`, `0047-*.patch` generated by diffing saved base copies against the working tree (`--label a/lcs/host/...`), verified by applying the whole series to `git archive HEAD` of `tools/src/lcs-recomp` and `cmp`-ing.
- Heavy jobs inside `gt-heavy.slice` (6 GB); never wait with `pgrep -f` loops.
- Commits: Conventional Commits, English, trailer `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`; PRs end with `🤖 Generated with [Claude Code](https://claude.com/claude-code)` and have "How to test manually".

## Review Focus

1. A register that changes inside a list but is read through another path (e.g. `0xEA` block transfer rewriting texture or CLUT memory with no register change) — the revision must bump on 0xEA and at every list start; pinned by Task 1's test `transfer_and_list_start_bump`.
2. Texture readiness changing without a register change (a texture uploaded or evicted between two draws of the same revision) — the fast path must re-check when the backend's texture generation changes; pinned by Task 4's verify mode and the `texture_generation` check.
3. The frameskip path (patch 0036) skipping screen draws — the fast path must sit after the frameskip early return so skipped draws still only advance the vertex pointer; pinned by Task 4 step ordering and a gate run with frameskip on (`gpu_perf.sh` runs with it).
4. Render-to-texture targets (mirror, reflections) between screen draws — a target change must bump the revision (0x9C/0x9D are registers, so they do) and `software_raster_skipped` must be re-evaluated per revision; pinned by Task 4 verify mode on the race route (mirror on screen).
5. Dual mode (`PSPRECOMP_GE_GPU_DUAL=1`, used by the GPU gate) — the software pass must not be affected: the fast path is GPU-only and runs only when `g_dual_pass != DualPass::SoftwareOnly`; pinned by the GPU gate in Tasks 3 and 5.

```cpp
#include "ge_state_revision.hpp"

namespace gt {

bool GeStateRevision::per_draw_register(std::uint32_t command) noexcept {
    switch (command) {
    case 0x01u: case 0x02u: case 0x04u:            // vertex / index address, PRIM
    case 0x10u: case 0x13u:                        // BASE, OFFSET
    case 0x08u: case 0x09u: case 0x0Au: case 0x0Bu: case 0x0Cu: case 0x0Du: case 0x0Eu: case 0x0Fu:  // list flow
    case 0xC8u:                                    // texture level: recomputed per draw (patch 0039 carries the LOD)
        return true;
    default:
        return false;
    }
}

void GeStateRevision::on_command(std::uint32_t command, std::uint32_t old_data, std::uint32_t data) noexcept {
    if (old_data != data && !per_draw_register(command)) ++value_;
}

void GeStateRevision::on_list_start() noexcept { ++value_; }
void GeStateRevision::on_block_transfer() noexcept { ++value_; }

} // namespace gt
```
